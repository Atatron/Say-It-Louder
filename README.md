# Say-It-Louder

Hackathon work for **You, Yourself**: a low-cost wearable that gives a person who hears voices two outside facts at the moment a voice is heard. Were their own speech muscles active? Was anyone nearby really speaking?

- [`docs/real-vs-imagined-voice.md`](docs/real-vs-imagined-voice.md): can a model tell a real voice from an inner one? Feasibility, signals, on-device models, data and a hackathon plan.
- [`edge/`](edge/): on-device prototype (ESP32-S3 + MyoWare 2.0 + microphone) with a Python reference implementation and tests.

Research prototype. Not a medical device. It does not diagnose, and it never tells anyone a voice is "not real".
